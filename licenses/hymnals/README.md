# Hymnal permission records

One file per hymnal the app bundles or the official repository distributes.
Keep the original permission correspondence (email or letter, as PDF) next to
the record. A hymnal may only be listed in `catalog/production/hymnals.json`
or bundled in the app once its record is complete.

Copy `_template.md` to `<book-id>.md` and fill in every field.
